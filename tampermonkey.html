DS Tools — één script voor alles

Eén script voor alle automatische tools van Delivery Support in DireXtion, de consumer portal en Sophia. Het bevat zelf geen tools: bij elke pagina haalt het de nieuwste versies op en start het de modules die bij die pagina horen. Welke modules aan staan, wordt geregeld op de beheerpagina. Een nieuwe module of een update komt vanzelf, zonder opnieuw te installeren.

Installeer er één: het gewone script draait de modules op productie, het dev-script ook die op test.

Modules

Live uit launcher/launcher.js (lijst AUTO) en launcher/status.json. Versie = @version van het bronbestand.

Installeren

  1. Je hebt de extensie Tampermonkey nodig (Chrome Web Store). Heb je het Service Check-script al, dan heb je hem.
  2. Klik bij DS Tools op Installeren. Tampermonkey opent een scherm met de code; klik daar op Installeren.
  3. Herlaad de pagina waar je mee bezig was.

Doet het script niets? Ga naar chrome://extensions → Tampermonkey → Details en controleer: de schakelaar staat aan, Toegang tot site staat op Op alle sites, en Gebruikersscripts toestaan staat aan (zie je die optie niet, zet dan rechtsboven Ontwikkelaarsmodus aan). In de console (filter DS Tools auto) staat per pagina welke modules er draaien.
Uitzetten of verwijderen: Tampermonkey-icoon → Dashboard.

Coolblue Service Check

Dit script is van David en staat los van DS Tools: het heeft een eigen toestemming nodig om Coolblue-pagina’s op te halen. Hier staat een kopie van de versie die zijn installatiepagina uitdeelt. Heb je het al (geplakt via Een nieuw script maken), dan hoef je niets te doen. Nieuw installeren kan hier; Tampermonkey haalt updates dan van deze kopie.

Losse scripts van vroeger

Planning-combi, EV-ritten, DS Logboek in Basic en de andere waren eerst elk een eigen script. Ze zijn nu modules van DS Tools. Heb je er nog een, verwijder hem dan (Tampermonkey-icoon → Dashboard) zodra DS Tools erop staat. Tot dan blijft hij werken en updates krijgen, en dubbel draaien kan niet: wie het eerst start, doet het werk.

Updates

  • Modules en tools komen vanzelf: bij het openen van een pagina opgehaald, de keer daarna actief. Een module uitzetten op de beheerpagina werkt vanaf de eerstvolgende paginalading.
  • Het script zelf verandert bijna nooit (alleen bij een nieuwe website). Tampermonkey controleert het ongeveer één keer per dag; meteen: Dashboard → Check for userscript updates.
  • Tot 5 minuten na een wijziging kan GitHub nog de vorige versie geven.
