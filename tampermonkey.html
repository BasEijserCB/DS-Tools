🧩 Tampermonkey-scripts

Scripts die vanzelf starten als je een DireXtion-pagina opent — geen klik op een bladwijzer nodig.

Installeren

  1. Je hebt de extensie Tampermonkey nodig (Chrome Web Store). Heb je het Service Check-script al, dan heb je hem.
  2. Klik bij een script op Installeren. Tampermonkey opent een scherm met de code; klik daar op Installeren.
  3. Herlaad de DireXtion-pagina waar het script voor is.

Doet een script niets? Ga naar chrome://extensions → Tampermonkey → Details en controleer: de schakelaar staat aan, Toegang tot site staat op Op alle sites, en Gebruikersscripts toestaan staat aan (zie je die optie niet, zet dan rechtsboven Ontwikkelaarsmodus aan).
Uitzetten of verwijderen: Tampermonkey-icoon → Dashboard.

Updates

  • De tool zelf (bijv. DS Logboek) wordt vanzelf bijgewerkt: bij het openen van de pagina opgehaald, de keer daarna actief.
  • Het script wordt door Tampermonkey ongeveer één keer per dag gecontroleerd. Meteen bijwerken: klik hier opnieuw op Installeren (Tampermonkey toont dan Bijwerken), of Dashboard → Check for userscript updates.
  • Tot 5 minuten na een wijziging kan GitHub nog de vorige versie geven. Staat er nog het oude versienummer, probeer het dan zo nog eens.
