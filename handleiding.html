🧰 DS Tools — handleiding

Per tool: waar je hem gebruikt, de stappen, en wat de kleuren en tekens betekenen. Het ? in de DS Tools-balk opent deze pagina bij de tools van de pagina waar je bent. Nog niet geïnstalleerd? Zie de installatiepagina.

↑ Alle tools
De balk
🧰 OpenenKlik op de bladwijzer DS Tools. Bovenin verschijnt een balk met de tools voor deze pagina; de rest staat onder Andere tools ▾.
▶ StartenKlik op een tool, of druk op het cijfer 1–9. De balk gaat daarna vanzelf dicht.
✕ SluitenEsc, het kruisje, of nog een klik op de bladwijzer.
↻ UpdateZie je rechtsonder “nieuwe versie gedownload”? Start de tool nog een keer, dan draait de nieuwe versie.
